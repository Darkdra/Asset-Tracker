# Asset Tracker

A private ledger for tracking net worth — what you own and what you owe,
all in one place.

## What it does

- **Organize freely.** Group your assets and liabilities into your own
  categories — banks, investments, property, anything — and break each one
  into named sections.
- **Track anything.** Add line items with a value each; negative values
  represent liabilities, so debts pull your total down just like assets
  build it up.
- **Watch it change.** The dashboard shows your current net worth and how
  it's moved over the past month, quarter, or all time, on a running chart.
- **Make it yours.** Switch between a dark, black-and-red theme and a
  light, white-and-gold theme.
- **Install it.** Add it to your phone or desktop home screen like a native
  app — it opens in its own window and keeps working (read-only) if you
  briefly lose connection.

## Access

This is a personal project for individual use — there's no public sign-up.
